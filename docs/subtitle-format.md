# DL Sound 字幕格式

## 把字幕放在哪里

将音频与同名的 UTF-8 字幕放在同一目录。例如，`第01话.mp3` 或 `第01话.wav` 都可以搭配 `第01话.vtt`、`第01话.lrc` 或 `第01话.srt`。在「我的 → 设置 → 文件与曲库 → 字幕目录」授权该目录，播放时会自动匹配文件名，扩展名大小写均可。

同目录有多份同名字幕时，自动匹配依次选用 `.vtt`、`.lrc`、`.srt`。想用另一份时，在播放页的「音轨操作 → 本曲字幕 → 导入字幕」选择文件。手动选择只绑定这一首音轨，点「恢复自动匹配」可重新使用同目录字幕。

## VTT 日中双语与上方假名

已有普通 VTT 可直接使用。制作双语字幕时，在同一条字幕中用 `<lang ja>` 标明日文、`<lang zh>` 标明中文。也支持 `ja-JP`、`zh-Hans` 等语言标签。可选的 `<ruby>` 包住原文和读音，`<rt>` 里写假名。例如以下内容可保存为 `第01话.vtt`。

```vtt
WEBVTT

00:00:01.250 --> 00:00:03.400
<lang ja><ruby>明日<rt>あした</rt></ruby>、また。</lang>
<lang zh>明天见。</lang>
```

选择「双」可同时看台词和译文，选择「日」或「中」可单独看一种语言。假名开关控制读音的显示。整条字幕未标语言时，各语言模式都显示原文并保留换行；仅凭两行的先后顺序无法确定翻译关系。播放器使用字幕的起止时间，忽略定位、样式和注释块。

## SRT

同名 SRT 直接按起止时间显示，支持编号、多行正文和字幕之间的停顿。切换「日／中／双」时，未标语言的 SRT 始终显示原文。若要分别切换日文和中文，推荐使用带语言标签的 VTT 或下面的双语 LRC。

```srt
1
00:00:01,250 --> 00:00:03,400
明天见。
```

## 已有 LRC 的约定

双语 LRC 用全角竖线 `｜` 分隔日文和中文。可在日文部分用 `{原文|平假名}` 指定词的读音，例如下面这条合成测试句。

```text
[00:01.250]{人間|にんげん}は言葉を使います。　｜　人类使用语言。
```

文件使用 UTF-8，可带 BOM。支持一行多个时间戳、相同时间的多条内容、长分钟数、`offset`、空白定时行和常见元数据。括号开头的场景提示在独立区域保留约 4 秒。VTT 和 SRT 使用每条台词的明确起止时间。

没有分隔符的普通行按日文展示。含假名的日文会进入自动分析，未标注且只有汉字的模糊行保留原文。要指定读音，可以直接写成 `{原文|平假名}`。

## 单独的日文与中文字幕

例如 `01.ja.vtt` 和 `01.zh.srt` 可以分别保存两种语言的时间轴，搭配 `01.wav` 使用。日文字幕中的假名在汉字上方显示。需要指定其他命名时，在「本曲字幕」分别选择日文和中文，或将所选后缀应用到同一目录的其他音轨。个人读音修正优先于字幕提供的读音，其余日文词可在本机生成假名。
