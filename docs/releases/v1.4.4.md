# DL Sound 1.4.4

- **查找本曲台词。** 在播放页打开「音轨操作 → 本曲字幕 → 查找台词」。日文、中文都能搜，结果显示时间和上下文。点选后回到歌词页，按该句时间和本曲偏移定位。搜索期间可以继续听。
- **换机备份可以补选。** 恢复时会分别标出同名候选和未找到的音轨。可对照路径选择，也能搜索改名后的文件。可以先恢复已匹配的资料，随后继续补选。相关歌单补齐后按原有曲序恢复，保留重复曲目。
- **歌词页按原因给出操作。** 目录需要授权时直接打开目录选择器，缺字幕时提示预期文件名。坏字幕可以重选，音频打不开时可以换一个音频。

适用于 Android 8.0 及以上，可从 1.4.3 覆盖升级。[下载 APK](https://github.com/ikarossuki/DLSound/releases/tag/v1.4.4) · [使用说明](../usage.md)
