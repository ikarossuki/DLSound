## 1.3.7 更新内容

**这次更新让日语音声更方便反复听。** 播放进度条下新增「复听与书签」，可以反复听一句台词，也可以给喜欢的片段留个书签。正式版的离线自动注音也已修复。

### 新功能

- **单句与 A–B 复听。** 有字幕时点「复听当前句」。没有字幕时，播放到想听的起点和终点，分别点「设 A 点」和「设 B 点」。支持播放 1、3、5 遍或无限循环，普通限次复听结束后会继续播放。
- **时间点和片段书签。** 可以给当前位置或 A–B 片段命名并保存。在「我的 → 我的书签」里跨曲回听，也可以在播放器里查看本曲书签。回听收藏片段时，最后一遍会在 B 点暂停。
- **本地作品库。** 从「文件夹 → 作品库」进入。带 RJ 编号的目录会自动列出，其他作品可手动指定目录。可以按作品名或 RJ 编号搜索，按声优、社团分组，并为同一作品记住偏好的音轨版本。

### 修复与改进

- **离线注音和字幕。** 修复了正式版可能无法加载日语词典，以及注音失败后无法重试的问题。字幕自带的 Ruby 优先保留。长字幕的读音处理移到后台；手动导入只读取、解析一次。切歌后，先前打开的读音修正框不会改到另一首歌。
- **播放队列与歌单。** 跨曲回听书签会保留原队列顺序，队外曲目会追加到末尾。歌单中同一首歌出现多次时，点播和删除都作用于选中的那一项。修复了队列写入失败后可能忽略后续删除的问题。
- **曲库与备份。** 刷新时遇到存储卷读取失败，会保留已有曲库。恢复前会检查显示偏好和读音关联，避免无效备份留下部分歌单；合并收藏时也会保留恢复期间的操作。
- **播放与整理。** 睡眠定时按实际播放时长累计，频繁暂停也能正确倒计时。编辑作品资料时锁定原目录，避免留下重复记录。异常 LRC 时间偏移会在超出可表示范围时被忽略。
- **其他维护。** 修复了手表同步代码中的队列移动、请求超时和设备更换处理，改进了回归测试与正式构建的 R8 映射归档。

### 安装与升级

从本版发行页的 **Assets** 下载 `DLSound-1.3.7.apk`，适用于 Android 8.0 及以上。已安装 1.3.6 正式版的用户可直接覆盖升级。书签、片段和作品整理信息保存在本机，当前手动换机备份尚未包含这三类数据。

正式签名包已在 Android API 37 手机模拟器上覆盖安装。MP3、WAV 分别搭配同名 VTT、LRC、SRT 的六种组合均可播放并显示字幕，双语 VTT 的假名显示在对应汉字上方。
