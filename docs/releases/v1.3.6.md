## 1.3.6 更新内容

- **同名字幕自动匹配。** 修复了 MP3 旁边已有 VTT 或 Himitsu JSON，播放器却提示找不到字幕的问题。首次播放时，在歌词页点「授权当前音乐文件夹」，确认音频所在目录。之后整个目录和子目录里的音轨都能自动匹配同名字幕，重启后授权仍然有效。已有的手动字幕选择会保留。
- **文件夹页可直接刷新音乐库。** 点击搜索左侧的刷新图标。扫描成功后提示「刷新完成」，超过 30 秒提示「刷新超时，请重试」。连续点击只发起一次刷新。
- **播放队列支持长按拖动。** 长按曲目并上下拖到目标位置，松手即可排序。轻点仍可点播，直接滑动可浏览队列。调整顺序会保留当前播放曲目，重启后仍按调整后的顺序排列。

## 安装与升级

在发行页的 **Assets** 中下载 `DLSound-1.3.6.apk`，适用于 Android 8.0 及以上。已安装 GitHub 正式版 1.3.4 或 1.3.5 的用户可直接覆盖升级，保留歌单、设置和播放记录。
