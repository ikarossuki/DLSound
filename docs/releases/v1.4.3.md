# DL Sound 1.4.3

1.4.3 汇集了上次公开版本 1.3.7 以来的更新。播放页、曲库、队列和歌词已经改用 Kotlin 原生界面。APK 已移除旧网页资源。

- **字幕和复听。** VTT、LRC、SRT 均可自动匹配或手动选择。支持日中分别计时、汉字上方的假名、个人读音修正和连续逐句复听。1.4.0 起停用外部 Himitsu JSON 字幕。以前绑定过这类文件的音轨会重新匹配受支持的字幕，也可以手动重选。原文件和换机备份继续保留。
- **曲库和设置。** 在「文件夹 → 更多」可进入作品库或手选音频文件夹。音乐人浏览、曲目排序和均衡器可从对应页面使用。全局播放偏好在「我的 → 设置」。
- **续听和备份。** 手选文件夹、文件管理器和曲库打开同一文件时，会识别可对应的书签地址。暂停后立刻切歌时，迟到的进度回调会被丢弃。恢复备份后再打开同名但大小不同的文件，会使用与实际文件相符的进度。曲库授权失效或仍在加载时，应用会提示稍后再导入或导出。
- **升级和队列。** 修复旧网页数据迁移时书签可能遮盖手填作品名、声优等资料的问题。已经升级过的设备会尝试从仍在本机的旧记录补回资料，并保留用户后续的编辑和删除。修复队列重排后显示的相邻曲目，以及重复撤销移除曲目时的错误。
- **后台耗电。** 暂停后停止周期性读取播放进度。普通锁屏播放降低采样频率，A–B 和逐句复听保留句末判断所需的精度。

## 安装与升级

本版在 Android API 37 模拟器上用正式签名包验证了覆盖升级、播放、后台和本机数据。[代码审查与回归记录](../reviews/v1.4.3-code-review.md)

支持 Android 8.0 及以上。下载 `DLSound-1.4.3.apk` 后直接覆盖安装，包名为 `local.dlsound.player`，版本号为 38。1.3.4 起的同签名正式版支持覆盖升级。早期使用其他签名的本地 1.3.3 无法直接覆盖安装。可在同一发布页用 `SHA256SUMS.txt` 核对下载文件。[下载 1.4.3](https://github.com/ikarossuki/DLSound/releases/tag/v1.4.3)
