# DL Sound 使用说明

## 本地播放与字幕

适用于 DL Sound 1.4.3。播放器使用 Android 原生界面，支持 UTF-8 编码的 VTT、LRC 和 SRT 字幕。升级后，旧版关联的已停用字幕会回到当前音轨的自动匹配，亦可在「本曲字幕」重新选择。音频、原字幕文件和换机备份格式继续保留。

升级时，如果书签所在目录曾被误登记为空作品，应用会从仍保存在本机的旧数据中补回原有作品名、声优等资料。换机备份请在音乐读取授权生效、曲库加载完成后打开。

锁屏后可以继续听。普通播放会减少进度读取，A–B 和逐句复听仍按原来的精度判断句尾。暂停后会保存续听位置，返回播放页即可继续。

1. 将音频和同名的 UTF-8 字幕放在同一目录。例如 `第01话.wav` 可以配 `第01话.vtt`，换成 MP3、LRC 或 SRT 也按同样方式命名。允许读取本地音乐。首次播放时，如果歌词页提示「允许读取同名字幕」，点「授权当前音乐文件夹」，在系统选择器确认音频所在目录。此目录和子目录里的其他音轨会自动匹配字幕，重新打开应用后授权仍然有效。也可从「我的 → 设置 → 文件与曲库 → 字幕目录」授权其他目录。
2. 在「文件夹」页选择「按目录浏览」，点文件夹逐层进入。点搜索左侧的刷新按钮可重新读取音乐库。切换到「平铺列表」后再切回，或关闭并重新启动应用，会恢复上次的浏览目录。如果原目录移走，会显示仍有音轨的最近一级上层目录。
3. 点音轨播放，点「歌词」或从封面向左滑，点「日／中／双」小按钮切换语言。按住并拖动歌词可预览该句时间，轻点一句跳转。双语 LRC 沿用「日文｜中文」，VTT 可用语言标签区分日中、用 Ruby 指定上方假名。普通 VTT、LRC、SRT 均可直接播放。示例见[字幕格式](subtitle-format.md)。
4. 试听其他音轨后，从曲库点回原音轨会接着上次的位置播放。自然播完的音轨下次从头开始。歌单按保存的曲序显示和播放。打开播放队列，轻点曲目可点播，长按曲目后上下拖动可调整顺序；拖到列表边缘可继续滚动。
5. 手动选择的字幕须含有效定时内容。选错文件时可重新选择，原来可用的字幕仍可继续使用。在没有台词的间奏中，播放器会提示当前位置没有可修正的台词。
6. 修正当前句时可以在原生输入框里编辑读音。只有有效平假名才能保存，点「恢复原读音」可移除个人修正。应用切到后台后继续播放，回到前台会显示最新进度。

### 手选音频文件夹

在「文件夹」页右上角点「更多 → 手选音频文件夹」，用 Android 的文件选择器授权作品所在目录。进入子目录后点音轨，播放器会读取同目录字幕，并按当前目录的顺序播放后续音轨。这个入口也能播放系统音乐库没有收录的文件。播放页左上角可返回所选文件夹，返回根目录后再返回即可回到曲库。

### 音乐人和曲目排序

底部的「音乐人」按音频标签中的音乐人分组。点名字即可浏览和播放其曲目。有两首以上曲目时，可在列表上方点「排序」，按曲名、音乐人、专辑或时长升降序排列，也可恢复默认顺序。搜索结果和「我的收藏」使用同一入口。点播和「播放全部」采用屏幕上的曲目顺序。自己编排的歌单按保存的曲序播放，歌单详情的「编辑歌单」可改名或删除歌单。

### 日文和中文各有一份字幕时

例如把 `01.wav`、`01.ja.vtt`、`01.zh.srt` 放在同一目录，打开歌词并选「双」。两份字幕各自按时间显示，日文 VTT 的 Ruby 会保留。日、中两侧都支持 VTT、LRC 和 SRT。若同时放有 `01.vtt` 等同名整合字幕，默认优先使用整合字幕。

文件名不符合这个例子时，在播放页右上角点「音轨操作 → 本曲字幕 → 分别选择日文和中文字幕」，先选日文，再选中文。从文件管理器或手选文件夹打开的音频，点「音轨操作」即可直接进入「本曲字幕」。如果整张作品都用同一命名方式，例如 `01.orig.vtt` 配 `01.cn.srt`，可以勾选「同目录其他音轨也使用这两个文件名后缀」，随后 `02.wav` 会按同一规则匹配。单曲选择和目录规则可以分别取消。

## 复听与书签

在播放进度条下点「复听与书签」。有台词时可选播放遍数并点「复听当前句」，起止位置会计入此曲的字幕偏移。没有字幕也可以用面板里的进度条定位，先点「设 A 点」，再向后定位并点「设 B 点」。选择 1、3、5 遍或无限循环后点「播放 A–B 区间」。有限次数的练习结束后接着播放，点「结束复听」可提前退出。切歌时会结束上一首的练习。

选择有限遍数后点「逐句连续复听」，从当前位置的台词开始，每句听完指定遍数后自动进入下一句。在台词间隙启动会从下一句开始。日中双文件采用日文原句的时间，计入当前音轨的字幕偏移。锁屏后练习继续，点「结束复听」可随时退出。

在同一面板下输入名称后，可以保存当前时间点，或收藏已设好 A、B 的片段。省略名称会按曲名和时间命名。回听收藏片段时，最后一遍在 B 点暂停。下次从「我的 → 我的书签」或「复听与书签 → 本曲书签」打开。通过文件管理器打开且仅获单文件授权的音频，可以用原文件重新打开后回听。

## 按作品整理音声

在「文件夹」页右上角点「更多 → 作品库」。名称含 RJ 编号的文件夹会自动列出，其他作品可点右上角的加号指定根目录。进入作品后，可直接选版本和继续收听。右上角的铅笔可修改作品名、填写声优和社团，多名声优用顿号分开。可按声优或社团分组，也可以搜索作品名与 RJ 编号。作品根目录下的直属音轨作为一组，每个一级子目录（含其下的音轨）作为一个版本。选择偏好版本后，下次进入同一作品仍会选中它。整理作品只保存本地信息，原文件位置保持不变。

听过的版本会在作品详情里显示「继续收听」、音轨名和进度。切换版本可以查看另一版的进度；点「从第一轨开始」可从当前版本的第一轨零秒播放。

## 我的与设置

「我的 → 设置」集中提供播放速度、顺序、睡眠定时、字幕语言、假名、字号、立体歌词、主题与文件访问。播放页保留当次收听的倍速、睡眠定时和复听。在「歌词」页可以直接切换日／中／双，点「字幕显示」可调整字号和假名。在播放页右上角点「音轨操作 → 本曲字幕」，可以导入字幕、恢复自动匹配、调整同步偏移或修正当前句读音。迷你播放器可随时回到播放页。

「我的 → 关于 DL Sound」显示安装包的实际版本和构建号。点「检查更新」会向 GitHub 查询最新正式发行版，发现新版可在浏览器打开下载页。开源许可和第三方声明可离线阅读。

在「我的 → 设置 → 播放 → 均衡器」选择应用均衡器，使用设备提供的预设，或拖动频段滑杆。可在同一面板关闭音效。设备有系统均衡器时也可从这里打开。

## 从文件管理器播放

在文件管理器点开 MP3 或 WAV，选择 DL Sound。此时单独播放这一个文件，曲库原有的队列会保留。点「歌词」查看字幕。文件提供方只授权了音频时，可以在歌词页选择字幕文件，也可以授权同名字幕所在的目录。按系统返回键可回到原应用。

## 换机

在「我的 → 设置 → 文件与曲库」导出备份，将备份、音频和字幕复制到新设备。授权并加载曲库后点「恢复备份」。播放器按音频文件名、字节数和时长匹配；找不到或有多个匹配的文件会列出。恢复会合并收藏，保留原歌单；同名歌单内容不同时另建一份。已关联音轨的读音修正与时间偏移按相同字幕内容重新生效。字幕文件和访问权限需要在新设备单独准备。Android 系统备份也包含显示偏好。

从 1.3.8 起，新导出的备份也包含时间点书签、A–B 片段、作品名、声优、社团和偏好版本。原地升级后再导出即可备份原有记录。移动作品后，在「作品库」打开原作品。如果目录已失联，直接点「重新关联作品目录」。也可以从右上角的编辑入口找到它，再选择包含各版本的新根目录。同名音轨按作品内完整相对路径区分。单独移动或改名的音轨，可以在「我的书签」点开失联的书签，按完整路径重新选择文件。

从 1.3.9 导出的备份包含曲库音轨的续听位置和上次收听时间。恢复后，在作品详情里选原来的版本，点「继续收听」。当两份音频的名称、大小和时长相同且作品已改名时，可重新关联作品根目录，播放器会按版本子目录恢复进度。重复导入时保留较新的收听记录。手选文件夹播放的文件也会记录进度，换机后需要重新授权，保留原有目录路径、文件名和文件大小即可继续。
